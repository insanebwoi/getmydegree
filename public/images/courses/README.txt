Drop photographs in this folder to customize images on the Courses/Programs page:

  courses-banner.jpg   (Top page banner background)
  courses-1.jpg        (Program showcase / class visual)
  courses-2.jpg        (Eligibility / admissions documentation visual)

Supported formats: .webp, .avif, .jpg, .jpeg, .png, .svg.
High-resolution images will be automatically optimized and cropped cleanly by the layout.
